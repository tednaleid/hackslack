# Launcher v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Bun Launcher that starts the Slack desktop app with the repo's `styles/*.css` applied, keeps them applied, and offers an Inspect mode that playwright-cli can attach to.

**Architecture:** Hexagonal. `src/core/StyleKeeper` keeps the combined Stylesheets applied to every Slack page and depends only on two ports in `src/core/ports.ts`: `SlackApp` and `Stylesheets`. The `SlackApp` adapter (`CdpSlackApp`) speaks the Chrome DevTools Protocol through a `CdpClient` over one of two transports (the debugging pipe in Normal mode, a WebSocket in Inspect mode) and gets those transports from a `SlackProcess` (macOS process control, or a fake Chromium in tests). A thin CLI in `src/cli` is the driving side, called by `just` recipes.

**Tech Stack:** Bun 1.3.14+ running TypeScript directly, `bun:test`, Node built-ins via `node:` imports, Bun globals (`WebSocket`, `fetch`, `Bun.serve`, `Bun.sleep`), `just`, playwright-cli (Inspect mode only, not imported by code).

**Spec:** `docs/superpowers/specs/2026-10-01-launcher-design.md`, with `CONTEXT.md` and `docs/adr/0001-pipe-by-default-port-on-demand.md`.

## Global Constraints

- No npm dependencies and no `package.json`. No build step, no `tsconfig.json`. Bun runs the `.ts` files directly.
- Every code file starts with two lines beginning `ABOUTME: ` (as `//` comments in TS, `#` in the justfile, `/* */` in CSS).
- Keep each file under about 150 lines; split by responsibility if one grows past that.
- No emoji, em dashes or status-marker characters in code, comments, docs or commit messages.
- Use `just` recipes to run things (`just test`, not `bun test`) once the recipe exists.
- Commit messages: a plain imperative summary line, optional body, and end with the line `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Never use `--no-verify`.
- Security rules (from the spec, verbatim):
  1. Normal mode opens no TCP listener. Inspect mode binds only 127.0.0.1 on a random port, and `just status` warns while it is open.
  2. The Launcher makes no network requests except to Slack's own debugging endpoint on 127.0.0.1 in Inspect mode.
  3. Only the `Target`, `Page` and `Runtime` CDP domains are used. `Runtime.evaluate` runs only the injection snippet generated from the CSS with `JSON.stringify`, or the constant expression that reads the applied CSS back.
  4. Logs never contain Slack message content. CDP events are not logged.
  5. The only child processes are Slack itself, `pgrep`, `lsof` and `osascript`.
- Facts from the spike that the code relies on: a Slack page is a CDP target with `type === "page"` and a URL matching `^https://app\.slack\.com/`; it is first announced with an empty URL and gets its Slack URL through `Target.targetInfoChanged`, which can arrive several times; Slack exits within about 0.3s of the pipe closing; Slack 4.52 ignores `--remote-debugging-port` when `--remote-debugging-pipe` is also given.
- `just start`, `just inspect` and `just smoke` restart Ted's Slack. Ask Ted before running any of them.

## Review Focus

- **A page announced before its URL is known, then updated several times** should be attached exactly once. Test: Task 5, "attaches once when a page's URL arrives after it was created".
- **Several saves in quick succession** should leave Slack with the last saved CSS and exactly one registered new-document script, so a reload cannot resurrect old CSS. Tests: Task 4, "ends with the last saved CSS after rapid changes"; Task 5, "replacing CSS leaves one new-document script with the latest CSS".
- **CSS containing quotes, backslashes, `</style>`, non-ASCII and U+2028** should be injected byte for byte. Test: Task 3, "adds one style element containing the CSS exactly".
- **Slack quitting on its own (auto-update, user quit)** should leave the Launcher logging the exit and `just status` saying Slack is not running or is running without the Launcher. Tests: Task 5, "reports Slack exiting when the connection closes"; Task 9, the "Slack is running without the Launcher" status case.
- **A missing `styles/` directory or a deleted Stylesheet** should fail the start with a clear error, or drop that file's rules on the next reload. Tests: Task 7, "rejects when the styles directory does not exist" and "drops a deleted file's CSS on the next load".

```ts
// ABOUTME: Encodes and decodes messages on Chromium's --remote-debugging-pipe.
// ABOUTME: Each message is UTF-8 JSON terminated by a single NUL byte.

export function encodeFrame(message: string): Buffer {
  return Buffer.concat([Buffer.from(message, "utf8"), Buffer.from([0])]);
}

export class FrameDecoder {
  private pending: Buffer = Buffer.alloc(0);

  push(chunk: Uint8Array): string[] {
    this.pending = Buffer.concat([this.pending, chunk]);
    const messages: string[] = [];
    let end: number;
    while ((end = this.pending.indexOf(0)) !== -1) {
      messages.push(this.pending.subarray(0, end).toString("utf8"));
      this.pending = this.pending.subarray(end + 1);
    }
    return messages;
  }
}
```

```ts
// ABOUTME: Small async helpers shared by the tests.
// ABOUTME: deferred promises, timeouts with a description, and polling until a condition holds.

export function deferred<T>() {
  let resolve!: (value: T) => void;
  let reject!: (error: unknown) => void;
  const promise = new Promise<T>((res, rej) => {
    resolve = res;
    reject = rej;
  });
  return { promise, resolve, reject };
}

export async function withTimeout<T>(promise: Promise<T>, ms: number, what: string): Promise<T> {
  let timer: ReturnType<typeof setTimeout> | undefined;
  const timeout = new Promise<never>((_, reject) => {
    timer = setTimeout(() => reject(new Error(`timed out after ${ms}ms waiting for ${what}`)), ms);
  });
  try {
    return await Promise.race([promise, timeout]);
  } finally {
    clearTimeout(timer);
  }
}

export async function eventually(check: () => boolean, ms = 1000, what = "condition"): Promise<void> {
  const deadline = Date.now() + ms;
  while (!check()) {
    if (Date.now() > deadline) throw new Error(`timed out after ${ms}ms waiting for ${what}`);
    await Bun.sleep(5);
  }
}
```

```ts
// ABOUTME: In-memory pair of connected Transports for tests.
// ABOUTME: Messages are delivered asynchronously, as they would be over a real pipe or socket.
import type { Transport } from "../../src/cdp/transport";

export function memoryTransportPair(): [Transport, Transport] {
  const handlers = [
    { message: (_message: string) => {}, close: (_reason: string) => {} },
    { message: (_message: string) => {}, close: (_reason: string) => {} },
  ];
  let closed = false;
  const side = (self: number, other: number): Transport => ({
    send: (message) => {
      if (!closed) queueMicrotask(() => handlers[other]!.message(message));
    },
    onMessage: (handler) => {
      handlers[self]!.message = handler;
    },
    onClose: (handler) => {
      handlers[self]!.close = handler;
    },
    close: () => {
      if (closed) return;
      closed = true;
      queueMicrotask(() => {
        handlers[0]!.close("closed");
        handlers[1]!.close("closed");
      });
    },
  });
  return [side(0, 1), side(1, 0)];
}
```

```ts
// ABOUTME: Minimal Chrome DevTools Protocol client over a Transport.
// ABOUTME: Matches responses to requests by id, routes events by method, and carries sessionIds.
import type { Transport } from "./transport";

export class CdpError extends Error {}

type EventHandler = (params: any, sessionId: string | undefined) => void;

interface Pending {
  method: string;
  resolve: (result: any) => void;
  reject: (error: Error) => void;
}

export class CdpClient {
  private nextId = 1;
  private readonly pending = new Map<number, Pending>();
  private readonly handlers = new Map<string, EventHandler[]>();
  private readonly closeHandlers: ((reason: string) => void)[] = [];
  private closedReason: string | null = null;

  constructor(private readonly transport: Transport) {
    transport.onMessage((message) => this.receive(message));
    transport.onClose((reason) => this.handleClose(reason));
  }

  send(method: string, params: Record<string, unknown> = {}, sessionId?: string): Promise<any> {
    if (this.closedReason !== null) {
      return Promise.reject(new CdpError(`${method}: connection closed (${this.closedReason})`));
    }
    const id = this.nextId++;
    const message: Record<string, unknown> = { id, method, params };
    if (sessionId) message.sessionId = sessionId;
    return new Promise((resolve, reject) => {
      this.pending.set(id, { method, resolve, reject });
      this.transport.send(JSON.stringify(message));
    });
  }

  on(method: string, handler: EventHandler): void {
    this.handlers.set(method, [...(this.handlers.get(method) ?? []), handler]);
  }

  onClose(handler: (reason: string) => void): void {
    this.closeHandlers.push(handler);
  }

  close(): void {
    this.transport.close();
    this.handleClose("closed by launcher");
  }

  private receive(raw: string): void {
    let message: any;
    try {
      message = JSON.parse(raw);
    } catch {
      return;
    }
    if (typeof message.id === "number") {
      const entry = this.pending.get(message.id);
      if (!entry) return;
      this.pending.delete(message.id);
      if (message.error) entry.reject(new CdpError(`${entry.method}: ${message.error.message}`));
      else entry.resolve(message.result ?? {});
      return;
    }
    if (typeof message.method === "string") {
      for (const handler of this.handlers.get(message.method) ?? []) {
        handler(message.params ?? {}, message.sessionId);
      }
    }
  }

  private handleClose(reason: string): void {
    if (this.closedReason !== null) return;
    this.closedReason = reason;
    for (const entry of this.pending.values()) {
      entry.reject(new CdpError(`${entry.method}: connection closed (${reason})`));
    }
    this.pending.clear();
    for (const handler of this.closeHandlers) handler(reason);
  }
}
```

```ts
// ABOUTME: Minimal stand-in for a browser document, enough to run the CSS injection snippet.
// ABOUTME: Used by the injection tests and by FakeChromium to evaluate expressions in a page.

export class FakeElement {
  id = "";
  textContent = "";
  parent: FakeContainer | null = null;

  constructor(readonly tagName: string) {}

  get isConnected(): boolean {
    return this.parent !== null;
  }
}

export class FakeContainer {
  readonly children: FakeElement[] = [];

  appendChild(element: FakeElement): FakeElement {
    element.parent = this;
    this.children.push(element);
    return element;
  }
}

export class FakeDocument {
  head: FakeContainer | null;
  documentElement: FakeContainer | null;
  private readonly listeners = new Map<string, (() => void)[]>();

  constructor(options: { parsed?: boolean } = {}) {
    const parsed = options.parsed ?? true;
    this.documentElement = parsed ? new FakeContainer() : null;
    this.head = parsed ? new FakeContainer() : null;
  }

  getElementById(id: string): FakeElement | null {
    return this.styleElements().find((element) => element.id === id) ?? null;
  }

  createElement(tagName: string): FakeElement {
    return new FakeElement(tagName.toUpperCase());
  }

  addEventListener(type: string, listener: () => void): void {
    this.listeners.set(type, [...(this.listeners.get(type) ?? []), listener]);
  }

  finishParsing(): void {
    this.documentElement ??= new FakeContainer();
    this.head ??= new FakeContainer();
    for (const listener of this.listeners.get("DOMContentLoaded") ?? []) listener();
  }

  styleElements(): FakeElement[] {
    return [...(this.head?.children ?? []), ...(this.documentElement?.children ?? [])];
  }
}

export function evaluateIn(doc: FakeDocument, expression: string): unknown {
  return new Function("document", `return ${expression}`)(doc);
}
```

```ts
export class FakeStylesheets implements Stylesheets {

  watcherCount = 0;
  private readonly listeners = new Set<() => void>();

    if (this.loadError) throw this.loadError;
    return this.css;

  watch(onChange: () => void): () => void {
    this.listeners.add(onChange);
```

```ts
// ABOUTME: The core: keeps the combined Stylesheets applied to every Slack page.
// ABOUTME: Applies on page ready, re-applies to all pages when the Stylesheets change, and reports stats.
import { errorMessage, type Log, shortId } from "./log";
import type { LaunchInfo, Mode, SlackApp, Stylesheets } from "./ports";

export interface KeeperStats {
  injectCount: number;
  lastInjectAt: string | null;
  pageCount: number;
}

export class StyleKeeper {
  readonly exited: Promise<string>;
  private resolveExited!: (reason: string) => void;
  private readonly pages = new Set<string>();
  private css = "";
  private injectCount = 0;
  private lastInjectAt: string | null = null;
  private stopWatching: () => void = () => {};
  private reloads: Promise<void> = Promise.resolve();

  constructor(
    private readonly slack: SlackApp,
    private readonly stylesheets: Stylesheets,
    private readonly log: Log,
    private readonly onStats: (stats: KeeperStats) => void = () => {},
  ) {
    this.exited = new Promise((resolve) => {
      this.resolveExited = resolve;
    });
  }

  async start(mode: Mode): Promise<LaunchInfo> {
    this.css = await this.stylesheets.load();
    this.stopWatching = this.stylesheets.watch(() => {
      this.reloads = this.reloads.then(() => this.reload());
    });
    try {
      return await this.slack.launch(mode, {
        pageReady: (page) => {
          this.pages.add(page.id);
          void this.apply(page.id);
        },
        pageGone: (pageId) => {
          this.pages.delete(pageId);
          this.publish();
        },
        exited: (reason) => {
          this.stopWatching();
          this.resolveExited(reason);
        },
      });
    } catch (error) {
      this.stopWatching();
      throw error;
    }
  }

  private async reload(): Promise<void> {
    try {
      this.css = await this.stylesheets.load();
    } catch (error) {
      this.log(`could not reload Stylesheets, keeping the previous CSS: ${errorMessage(error)}`);
      return;
    }
    this.log(`Stylesheets changed; applying to ${this.pages.size} page(s)`);
    await Promise.all([...this.pages].map((pageId) => this.apply(pageId)));
  }

  private async apply(pageId: string): Promise<void> {
    try {
      await this.slack.applyCss(pageId, this.css);
      this.injectCount++;
      this.lastInjectAt = new Date().toISOString();
      this.log(`applied Stylesheets to page ${shortId(pageId)}`);
    } catch (error) {
      this.log(`could not apply Stylesheets to page ${shortId(pageId)}: ${errorMessage(error)}`);
    }
    this.publish();
  }

  private publish(): void {
    this.onStats({ injectCount: this.injectCount, lastInjectAt: this.lastInjectAt, pageCount: this.pages.size });
  }
}
```

```ts
// ABOUTME: Scripted stand-in for Chromium's DevTools endpoint, speaking CDP over an in-memory Transport.
// ABOUTME: Tracks targets, sessions, new-document scripts and a FakeDocument for each attached page.
import type { Transport } from "../../src/cdp/transport";
import { evaluateIn, FakeDocument } from "./fakeDocument";
import { memoryTransportPair } from "./memoryTransport";

export interface FakeTarget {
  targetId: string;
  type: string;
  url: string;
}

export const SLACK_TARGET: FakeTarget = {
  targetId: "PAGE-0001",
  type: "page",
  url: "https://app.slack.com/client/T0000001",
};

interface Request {
  id: number;
  method: string;
  params?: any;
  sessionId?: string;
}

export class FakeChromium {
  readonly clientTransport: Transport;
  readonly documents = new Map<string, FakeDocument>();
  readonly newDocumentScripts = new Map<string, Map<string, string>>();
  private readonly peer: Transport;
  private readonly received: string[] = [];
  private readonly sessionTargets = new Map<string, string>();
  private nextScriptId = 1;

  constructor(private readonly targets: FakeTarget[] = [SLACK_TARGET]) {
    const [client, peer] = memoryTransportPair();
    this.clientTransport = client;
    this.peer = peer;
    peer.onMessage((raw) => this.handle(JSON.parse(raw)));
  }

  callsTo(method: string): number {
    return this.received.filter((received) => received === method).length;
  }

  changeTarget(target: FakeTarget): void {
    this.emit("Target.targetInfoChanged", { targetInfo: target });
  }

  destroyTarget(targetId: string): void {
    for (const [sessionId, id] of this.sessionTargets) if (id === targetId) this.sessionTargets.delete(sessionId);
    this.emit("Target.targetDestroyed", { targetId });
  }

  reloadPage(targetId: string): void {
    const doc = new FakeDocument({ parsed: false });
    this.documents.set(targetId, doc);
    for (const source of this.newDocumentScripts.get(targetId)?.values() ?? []) evaluateIn(doc, source);
    doc.finishParsing();
  }

  disconnect(): void {
    this.peer.close();
  }

  private emit(method: string, params: object): void {
    this.peer.send(JSON.stringify({ method, params }));
  }

  private handle(request: Request): void {
    this.received.push(request.method);
    const params = request.params ?? {};
    const reply = (result: object) => this.peer.send(JSON.stringify({ id: request.id, result }));
    const fail = (message: string) => this.peer.send(JSON.stringify({ id: request.id, error: { code: -32000, message } }));
    const targetId = request.sessionId ? this.sessionTargets.get(request.sessionId) : undefined;
    if (request.sessionId && !targetId) return fail(`Session with given id not found: ${request.sessionId}`);

    switch (request.method) {
      case "Target.setDiscoverTargets":
        reply({});
        for (const targetInfo of this.targets) this.emit("Target.targetCreated", { targetInfo });
        return;
      case "Target.attachToTarget": {
        const sessionId = `SESSION-${params.targetId}`;
        this.sessionTargets.set(sessionId, params.targetId);
        this.documents.set(params.targetId, new FakeDocument());
        this.newDocumentScripts.set(params.targetId, new Map());
        return reply({ sessionId });
      }
      case "Page.enable":
        return reply({});
      case "Page.addScriptToEvaluateOnNewDocument": {
        const identifier = String(this.nextScriptId++);
        this.newDocumentScripts.get(targetId!)!.set(identifier, params.source);
        return reply({ identifier });
      }
      case "Page.removeScriptToEvaluateOnNewDocument":
        this.newDocumentScripts.get(targetId!)!.delete(params.identifier);
        return reply({});
      case "Runtime.evaluate":
        try {
          return reply({ result: { value: evaluateIn(this.documents.get(targetId!)!, params.expression) } });
        } catch (error) {
          return reply({ result: { type: "object" }, exceptionDetails: { text: String(error) } });
        }
      default:
        return fail(`FakeChromium does not handle ${request.method}`);
    }
  }
}
```

```ts
// ABOUTME: Finds Slack pages over CDP, attaches to each once, and applies CSS that survives reloads.
// ABOUTME: Uses only the Target, Page and Runtime domains; CSS changes for one page are applied in call order.
import type { CdpClient } from "../cdp/cdpClient";
import { buildInjectionSource, READ_APPLIED_CSS } from "../cdp/injection";
import { errorMessage, type Log, shortId } from "../core/log";
import type { SlackAppEvents } from "../core/ports";

export const SLACK_PAGE_URL = /^https:\/\/app\.slack\.com\//;

interface TargetInfo {
  targetId: string;
  type: string;
  url: string;
}

export class CdpSlackSession {
  private readonly sessions = new Map<string, string>();
  private readonly attaching = new Set<string>();
  private readonly scripts = new Map<string, string>();
  private readonly queues = new Map<string, Promise<void>>();

  constructor(
    private readonly cdp: CdpClient,
    private readonly events: SlackAppEvents,
    private readonly log: Log,
  ) {}

  async start(): Promise<void> {
    this.cdp.on("Target.targetCreated", (params) => this.consider(params.targetInfo));
    this.cdp.on("Target.targetInfoChanged", (params) => this.consider(params.targetInfo));
    this.cdp.on("Target.targetDestroyed", (params) => this.forget(params.targetId));
    this.cdp.on("Target.detachedFromTarget", (params) => this.forget(params.targetId));
    this.cdp.onClose((reason) => this.events.exited(reason));
    await this.cdp.send("Target.setDiscoverTargets", { discover: true });
  }

  applyCss(pageId: string, css: string): Promise<void> {
    const previous = this.queues.get(pageId) ?? Promise.resolve();
    const next = previous.catch(() => {}).then(() => this.replaceCss(pageId, css));
    this.queues.set(pageId, next);
    return next;
  }

  async readAppliedCss(pageId: string): Promise<string | null> {
    const value = await this.evaluate(this.sessionFor(pageId), READ_APPLIED_CSS);
    return typeof value === "string" ? value : null;
  }

  private consider(info: TargetInfo): void {
    if (info.type !== "page" || !SLACK_PAGE_URL.test(info.url)) return;
    if (this.sessions.has(info.targetId) || this.attaching.has(info.targetId)) return;
    this.attaching.add(info.targetId);
    void this.attach(info).finally(() => this.attaching.delete(info.targetId));
  }

  private async attach(info: TargetInfo): Promise<void> {
    try {
      const { sessionId } = await this.cdp.send("Target.attachToTarget", { targetId: info.targetId, flatten: true });
      await this.cdp.send("Page.enable", {}, sessionId);
      this.sessions.set(info.targetId, sessionId);
      this.log(`attached to Slack page ${shortId(info.targetId)}`);
      this.events.pageReady({ id: info.targetId, url: info.url });
    } catch (error) {
      this.log(`could not attach to page ${shortId(info.targetId)}: ${errorMessage(error)}`);
    }
  }

  private forget(targetId: string): void {
    this.scripts.delete(targetId);
    this.queues.delete(targetId);
    if (this.sessions.delete(targetId)) this.events.pageGone(targetId);
  }

  private async replaceCss(pageId: string, css: string): Promise<void> {
    const sessionId = this.sessionFor(pageId);
    const source = buildInjectionSource(css);
    const previous = this.scripts.get(pageId);
    if (previous) await this.cdp.send("Page.removeScriptToEvaluateOnNewDocument", { identifier: previous }, sessionId);
    const { identifier } = await this.cdp.send("Page.addScriptToEvaluateOnNewDocument", { source }, sessionId);
    this.scripts.set(pageId, identifier);
    await this.evaluate(sessionId, source);
  }

  private async evaluate(sessionId: string, expression: string): Promise<unknown> {
    const response = await this.cdp.send("Runtime.evaluate", { expression, returnByValue: true }, sessionId);
    if (response.exceptionDetails) throw new Error(`evaluation failed: ${response.exceptionDetails.text}`);
    return response.result?.value;
  }

  private sessionFor(pageId: string): string {
    const sessionId = this.sessions.get(pageId);
    if (!sessionId) throw new Error(`no attached Slack page ${shortId(pageId)}`);
    return sessionId;
  }
}
```

```ts
// ABOUTME: Transport over Slack's --remote-debugging-pipe: writes to its fd 3 and reads from its fd 4.
// ABOUTME: Only the process that spawned Slack holds these fds; nothing listens on the network.
import type { Readable, Writable } from "node:stream";
import { encodeFrame, FrameDecoder } from "./pipeFraming";
import type { Transport } from "./transport";

export function pipeTransport(output: Writable, input: Readable): Transport {
  const decoder = new FrameDecoder();
  let onMessage = (_message: string) => {};
  let onClose = (_reason: string) => {};
  let closed = false;
  const finish = (reason: string) => {
    if (closed) return;
    closed = true;
    onClose(reason);
  };

  input.on("data", (chunk: Buffer) => {
    for (const message of decoder.push(chunk)) onMessage(message);
  });
  input.on("end", () => finish("pipe closed by Slack"));
  input.on("error", (error) => finish(`pipe error: ${error.message}`));
  output.on("error", (error) => finish(`pipe error: ${error.message}`));

  return {
    send: (message) => {
      if (!closed) output.write(encodeFrame(message));
    },
    onMessage: (handler) => {
      onMessage = handler;
    },
    onClose: (handler) => {
      onClose = handler;
    },
    close: () => {
      output.end();
    },
  };
}
```

```ts
// ABOUTME: Transport over a WebSocket to Slack's debugging port, used only in Inspect mode.
// ABOUTME: Uses Bun's built-in WebSocket client; the URL always points at 127.0.0.1.
import type { Transport } from "./transport";

export function webSocketTransport(url: string): Promise<Transport> {
  return new Promise((resolve, reject) => {
    const socket = new WebSocket(url);
    let onMessage = (_message: string) => {};
    let onClose = (_reason: string) => {};
    let opened = false;

    socket.onopen = () => {
      opened = true;
      resolve({
        send: (message) => socket.send(message),
        onMessage: (handler) => {
          onMessage = handler;
        },
        onClose: (handler) => {
          onClose = handler;
        },
        close: () => socket.close(),
      });
    };
    socket.onmessage = (event) => onMessage(String(event.data));
    socket.onerror = () => {
      if (!opened) reject(new Error(`could not open a WebSocket to ${url}`));
    };
    socket.onclose = (event) => {
      if (opened) onClose(`websocket closed (code ${event.code})`);
      else reject(new Error(`WebSocket to ${url} closed before opening (code ${event.code})`));
    };
  });
}
```

```ts
  slackPid: number;
  port: number | null;

  start(mode: Mode): Promise<SlackConnection>;
}

export class CdpSlackApp implements SlackApp {
  private cdp: CdpClient | null = null;
  private session: CdpSlackSession | null = null;

    private readonly slackProcess: SlackProcess,
    private readonly log: Log,
  ) {}

  async launch(mode: Mode, events: SlackAppEvents): Promise<LaunchInfo> {
    const connection = await this.slackProcess.start(mode);
    this.cdp = new CdpClient(connection.transport);

    await this.session.start();
    return { slackPid: connection.slackPid, port: connection.port };

    return this.requireSession().readAppliedCss(pageId);
  }

  async close(): Promise<void> {
    this.cdp?.close();
  }

  private requireSession(): CdpSlackSession {
    if (!this.session) throw new Error("Slack has not been launched");
    return this.session;
  }
}
```

```ts
export class FsStylesheets implements Stylesheets {
  constructor(
    private readonly dir: string,
    private readonly debounceMs = 100,
  ) {}

  async load(): Promise<string> {
    const names = (await readdir(this.dir)).filter(isStylesheet).sort();
    const parts = await Promise.all(
      names.map(async (name) => `/* ${name} */\n${await readFile(join(this.dir, name), "utf8")}`),
    );
    return parts.join("\n");
  }

  watch(onChange: () => void): () => void {
    let timer: ReturnType<typeof setTimeout> | undefined;
    const watcher = watch(this.dir, (_event, name) => {
      if (name && !isStylesheet(String(name))) return;
      clearTimeout(timer);
      timer = setTimeout(onChange, this.debounceMs);
    });
    return () => {
      clearTimeout(timer);
      watcher.close();
    };
  }
}
```

```ts
// ABOUTME: macOS process control for the Slack app: find it, list it, quit it, and find its debugger URL.
// ABOUTME: Runs only pgrep, lsof and osascript, and never touches Slack.app's files.
import { spawnSync } from "node:child_process";
import { existsSync } from "node:fs";
import { createServer } from "node:net";
import { homedir } from "node:os";
import { join } from "node:path";
import type { Log } from "../core/log";

export const SLACK_BUNDLE_ID = "com.tinyspeck.slackmacgap";
const BINARY_IN_BUNDLE = "Slack.app/Contents/MacOS/Slack";

export function findSlackBinary(): string {
  const candidates = [join("/Applications", BINARY_IN_BUNDLE), join(homedir(), "Applications", BINARY_IN_BUNDLE)];
  const found = candidates.find((path) => existsSync(path));
  if (!found) throw new Error(`Slack not found; looked in ${candidates.join(" and ")}`);
  return found;
}

export function runningSlackPids(): number[] {
  const result = spawnSync("pgrep", ["-x", "Slack"], { encoding: "utf8" });
  return result.stdout.split("\n").filter(Boolean).map(Number);
}

export function listeningPorts(pid: number): number[] {
  const result = spawnSync("lsof", ["-nP", "-iTCP", "-sTCP:LISTEN", "-a", "-p", String(pid)], { encoding: "utf8" });
  return [...result.stdout.matchAll(/:(\d+) \(LISTEN\)/g)].map((match) => Number(match[1]));
}

export function isProcessAlive(pid: number): boolean {
  try {
    process.kill(pid, 0);
    return true;
  } catch (error) {
    return (error as NodeJS.ErrnoException).code === "EPERM";
  }
}

export async function waitUntil(check: () => boolean, timeoutMs: number, intervalMs = 200): Promise<boolean> {
  const deadline = Date.now() + timeoutMs;
  while (Date.now() < deadline) {
    if (check()) return true;
    await Bun.sleep(intervalMs);
  }
  return check();
}

export async function quitRunningSlack(log: Log): Promise<void> {
  const stopped = () => runningSlackPids().length === 0;
  if (stopped()) return;
  log("asking the running Slack to quit");
  spawnSync("osascript", ["-e", `tell application id "${SLACK_BUNDLE_ID}" to quit`]);
  if (await waitUntil(stopped, 10_000)) return;
  log("Slack did not quit; sending SIGTERM");
  signalSlack("SIGTERM");
  if (await waitUntil(stopped, 5_000)) return;
  log("Slack did not exit; sending SIGKILL");
  signalSlack("SIGKILL");
  if (!(await waitUntil(stopped, 2_000))) throw new Error("could not stop the running Slack");
}

function signalSlack(signal: NodeJS.Signals): void {
  for (const pid of runningSlackPids()) {
    try {
      process.kill(pid, signal);
    } catch {
      // The process exited between pgrep and kill.
    }
  }
}

export function pickFreePort(): Promise<number> {
  return new Promise((resolve, reject) => {
    const server = createServer();
    server.once("error", reject);
    server.listen(0, "127.0.0.1", () => {
      const address = server.address();
      const port = typeof address === "object" && address ? address.port : 0;
      server.close(() => resolve(port));
    });
  });
}

export async function waitForDebuggerUrl(port: number, timeoutMs: number): Promise<string> {
  const deadline = Date.now() + timeoutMs;
  while (Date.now() < deadline) {
    try {
      const response = await fetch(`http://127.0.0.1:${port}/json/version`);
      const body = (await response.json()) as { webSocketDebuggerUrl?: string };
      if (body.webSocketDebuggerUrl) return body.webSocketDebuggerUrl;
    } catch {
      // Slack has not opened the port yet.
    }
    await Bun.sleep(250);
  }
  throw new Error(`Slack did not open its debugging port ${port} within ${timeoutMs}ms`);
}
```

```ts
// ABOUTME: Starts the Slack app on macOS in Normal mode (debugging pipe) or Inspect mode (loopback port).
// ABOUTME: Quits any running Slack first; Slack 4.52 cannot use the pipe and a port at the same time.
import { spawn } from "node:child_process";
import type { Readable, Writable } from "node:stream";
import { pipeTransport } from "../cdp/pipeTransport";
import { webSocketTransport } from "../cdp/webSocketTransport";
import type { Log } from "../core/log";
import type { Mode } from "../core/ports";
import type { SlackConnection, SlackProcess } from "./cdpSlackApp";
import { findSlackBinary, pickFreePort, quitRunningSlack, waitForDebuggerUrl } from "./macProcesses";

export class MacSlackProcess implements SlackProcess {
  constructor(
    private readonly log: Log,
    private readonly binaryPath: string = findSlackBinary(),
  ) {}

  async start(mode: Mode): Promise<SlackConnection> {
    await quitRunningSlack(this.log);
    return mode === "normal" ? this.startWithPipe() : this.startWithPort();
  }

  private startWithPipe(): SlackConnection {
    const child = spawn(this.binaryPath, ["--remote-debugging-pipe"], {
      stdio: ["ignore", "ignore", "ignore", "pipe", "pipe"],
    });
    child.on("error", (error) => this.log(`Slack process error: ${error.message}`));
    if (child.pid === undefined) throw new Error(`could not start ${this.binaryPath}`);
    child.on("exit", (code, signal) => this.log(`Slack process exited code=${code} signal=${signal}`));
    this.log(`started Slack pid=${child.pid} in Normal mode`);
    const transport = pipeTransport(child.stdio[3] as Writable, child.stdio[4] as Readable);
    return { transport, slackPid: child.pid, port: null };
  }

  private async startWithPort(): Promise<SlackConnection> {
    const port = await pickFreePort();
    const child = spawn(this.binaryPath, [`--remote-debugging-port=${port}`], { detached: true, stdio: "ignore" });
    child.on("error", (error) => this.log(`Slack process error: ${error.message}`));
    if (child.pid === undefined) throw new Error(`could not start ${this.binaryPath}`);
    child.unref();
    this.log(`started Slack pid=${child.pid} in Inspect mode; debugging port ${port} is open on 127.0.0.1`);
    const url = await waitForDebuggerUrl(port, 30_000);
    return { transport: await webSocketTransport(url), slackPid: child.pid, port };
  }
}
```

```ts
// ABOUTME: Builds the text `just status` prints, warning first whenever Slack has a debugging port open.
// ABOUTME: describeStatus is pure; observeProcesses gathers the facts it needs from the system.
import { isProcessAlive, listeningPorts, runningSlackPids } from "../slack/macProcesses";
import type { LauncherState } from "./state";

export interface ObservedProcesses {
  launcherAlive: boolean;
  slackPids: number[];
  listeningPorts: number[];
}

export function describeStatus(state: LauncherState | null, seen: ObservedProcesses): string[] {
  const lines: string[] = [];
  if (seen.listeningPorts.length > 0) {
    const ports = seen.listeningPorts.map((port) => `127.0.0.1:${port}`).join(", ");
    lines.push(
      `WARNING: Slack has a debugging port open on ${ports}. Any local process can control your Slack session. Run \`just start\` to return to Normal mode.`,
    );
  }
  if (seen.slackPids.length === 0) {
    lines.push("Slack is not running.");
    if (state?.exitReason) lines.push(`Last exit: ${state.exitReason}`);
    return lines;
  }
  const managed =
    state !== null && seen.launcherAlive && state.slackPid !== null && seen.slackPids.includes(state.slackPid);
  if (!managed || state === null) {
    lines.push("Slack is running without the Launcher, so the Stylesheets are not applied. Run `just start`.");
    return lines;
  }
  lines.push(`Mode: ${state.mode === "normal" ? "Normal" : "Inspect"}`);
  lines.push(`Slack pid ${state.slackPid}, Launcher pid ${state.launcherPid}`);
  lines.push(
    `Stylesheets applied ${state.injectCount} time(s) across ${state.pageCount} page(s); last at ${state.lastInjectAt ?? "never"}`,
  );
  return lines;
}

export function observeProcesses(state: LauncherState | null): ObservedProcesses {
  const slackPids = runningSlackPids();
  return {
    launcherAlive: state !== null && isProcessAlive(state.launcherPid),
    slackPids,
    listeningPorts: slackPids.flatMap(listeningPorts),
  };
}
```

```ts
// ABOUTME: The long-running Launcher: starts Slack, keeps the Stylesheets applied, and records its state.
// ABOUTME: In Normal mode Slack exits when this process does, because the debugging pipe closes.
import { errorMessage, type Log } from "../core/log";
import type { Mode } from "../core/ports";
import { StyleKeeper } from "../core/styleKeeper";
import { CdpSlackApp } from "../slack/cdpSlackApp";
import { MacSlackProcess } from "../slack/macSlackProcess";
import { FsStylesheets } from "../stylesheets/fsStylesheets";
import { type LauncherState, STYLES_DIR, writeState } from "./state";

export async function runLauncher(mode: Mode): Promise<number> {
  const log: Log = (message) => console.log(`${new Date().toISOString()} ${message}`);
  let state: LauncherState = {
    launcherPid: process.pid,
    mode,
    slackPid: null,
    port: null,
    startedAt: new Date().toISOString(),
    injectCount: 0,
    lastInjectAt: null,
    pageCount: 0,
    exitReason: null,
  };
  const update = (changes: Partial<LauncherState>) => {
    state = { ...state, ...changes };
    writeState(state);
  };
  update({});

  const slack = new CdpSlackApp(new MacSlackProcess(log), log);
  const keeper = new StyleKeeper(slack, new FsStylesheets(STYLES_DIR), log, (stats) => update(stats));
  for (const signal of ["SIGTERM", "SIGINT"] as const) {
    process.on(signal, async () => {
      log(`received ${signal}; releasing Slack`);
      update({ exitReason: `Launcher stopped by ${signal}` });
      await slack.close();
      process.exit(0);
    });
  }

  try {
    const info = await keeper.start(mode);
    update({ slackPid: info.slackPid, port: info.port });
    log(`Slack pid=${info.slackPid} running in ${mode} mode${info.port ? ` with debugging port ${info.port}` : ""}`);
  } catch (error) {
    log(`could not start Slack: ${errorMessage(error)}`);
    update({ exitReason: `could not start Slack: ${errorMessage(error)}` });
    return 1;
  }

  const reason = await keeper.exited;
  log(`Slack exited: ${reason}`);
  update({ slackPid: null, exitReason: reason });
  return 0;
}
```

```ts
import { LOG_PATH, MAIN_PATH, readState, REPO_ROOT, STATE_DIR } from "./state";
import { describeStatus, observeProcesses } from "./status";

export async function startInBackground(mode: Mode): Promise<number> {
  await stopRunningLauncher();
  mkdirSync(STATE_DIR, { recursive: true });
  const logFd = openSync(LOG_PATH, "a");
  const child = spawn(process.execPath, [MAIN_PATH, "run", mode], {
    cwd: REPO_ROOT,
    detached: true,
    stdio: ["ignore", logFd, logFd],
  });
  child.unref();
  console.log(`Launcher started (pid ${child.pid}); restarting Slack in ${mode === "normal" ? "Normal" : "Inspect"} mode`);

  const settled = () => {
    const state = readState();
    return state?.launcherPid === child.pid && (state.injectCount > 0 || state.exitReason !== null);
  };
  const ready = await waitUntil(settled, 45_000, 250);
  const state = readState();
  if (!ready || state === null || state.exitReason !== null) {
    const why = state?.exitReason ? `: ${state.exitReason}` : " within 45s";
    console.error(`The Launcher did not apply the Stylesheets${why}. See \`just logs\`.`);
    return 1;
  }
  for (const line of describeStatus(state, observeProcesses(state))) console.log(line);
  return 0;
}

async function stopRunningLauncher(): Promise<void> {
  const state = readState();
  if (state === null || !isProcessAlive(state.launcherPid)) return;
  process.kill(state.launcherPid, "SIGTERM");
  if (!(await waitUntil(() => !isProcessAlive(state.launcherPid), 5_000))) {
    process.kill(state.launcherPid, "SIGKILL");
  }
}
```

```ts
// ABOUTME: Command-line entry point used by the justfile recipes.
// ABOUTME: Commands: run <mode>, start <mode>, status, port.
import type { Mode } from "../core/ports";
import { isProcessAlive } from "../slack/macProcesses";
import { runLauncher } from "./run";
import { startInBackground } from "./start";
import { readState } from "./state";
import { describeStatus, observeProcesses } from "./status";

function parseMode(value: string | undefined): Mode {
  if (value === "normal" || value === "inspect") return value;
  console.error(`mode must be "normal" or "inspect", got "${value ?? ""}"`);
  process.exit(2);
}

const [command, modeArgument] = process.argv.slice(2);

switch (command) {
  case "run":
    process.exit(await runLauncher(parseMode(modeArgument)));
  case "start":
    process.exit(await startInBackground(parseMode(modeArgument)));
  case "status": {
    const state = readState();
    for (const line of describeStatus(state, observeProcesses(state))) console.log(line);
    break;
  }
  case "port": {
    const state = readState();
    if (state?.mode !== "inspect" || state.port === null || !isProcessAlive(state.launcherPid)) {
      console.error("Slack is not in Inspect mode. Run `just inspect` first.");
      process.exit(1);
    }
    console.log(state.port);
    break;
  }
  default:
    console.error("usage: main.ts run <normal|inspect> | start <normal|inspect> | status | port");
    process.exit(2);
}
```

````markdown
# Changing how Slack looks

How to find an element in Slack's UI and write a Stylesheet that hides or restyles it.

## 1. Enter Inspect mode

Ask Ted first: this restarts Slack.

```bash
just inspect
just attach
```

`just status` now starts with a WARNING, because any local process can control Slack while the debugging port is open. Keep the session short.

## 2. Find the element

Prefer small, targeted queries over `playwright-cli snapshot`, which captures the whole UI including message text. Do not copy message content into files, commits or replies.

List the `data-qa` attributes and labels in a region, for example the Tab rail:

```bash
playwright-cli eval "JSON.stringify([...document.querySelectorAll('[data-qa=\"tabs_full_width_class\"] button')].map(e => [e.getAttribute('data-qa'), e.getAttribute('aria-label')]))"
```

Walk up from an element to find the container that also holds its label:

```bash
playwright-cli eval "(() => { const out = []; for (let e = document.querySelector('[data-qa=\"tab_rail_home_button\"]'), n = 0; e && n < 5; e = e.parentElement, n++) out.push([e.tagName, e.getAttribute('data-qa'), String(e.className).slice(0, 60)]); return JSON.stringify(out); })()"
```

Some elements exist only in some workspaces. To switch workspace, click the nth `[data-qa="team_sidebar_item"]`:

```bash
playwright-cli eval "document.querySelectorAll('[data-qa=\"team_sidebar_item\"]')[4].click()"
```

All workspaces share one Slack page; switching changes its URL and does not reload the Stylesheets.

## 3. Choose a selector

- Prefer `data-qa` attributes. They are Slack's test hooks and change less often than class names.
- Avoid hashed class names such as `button__zEiFQ`; they change between Slack releases.
- To hide an element together with its label, hide the nearest container with a `data-qa` attribute, using `:has()`:
  `[data-qa="draggable_tab_item"]:has([data-qa="tab_rail_slackbot_button"])`.
- Always add `!important` to `display: none`.

## 4. Write the Stylesheet

Put each concern in its own file under `styles/`, starting with two `ABOUTME:` lines in a CSS comment. Files are combined in filename order. The Launcher applies a saved file within about a second, with no restart.

Check that the rule took effect:

```bash
playwright-cli eval "getComputedStyle(document.querySelector('[data-qa=\"tab_rail_slackbot_button\"]')).display"
playwright-cli screenshot --filename=check.png
```

Screenshots land in `.playwright-cli/`, which git ignores. Crop to the region you changed before looking at one, so message content stays out of the conversation.

## 5. Leave Inspect mode

```bash
just detach
just start
just status
```

`just status` must show no WARNING. Then commit the new or changed file in `styles/`.
````

`docs/security.md`:
```markdown
# Launcher security rules

The Launcher can control Ted's logged-in Slack session, so it keeps these rules. A change that breaks one needs Ted's agreement and an ADR.

1. Normal mode opens no TCP listener. It uses `--remote-debugging-pipe`, whose file descriptors only the Launcher holds. Inspect mode binds only 127.0.0.1 on a random port, and `just status` warns while it is open.
2. The Launcher makes no network requests except to Slack's own debugging endpoint on 127.0.0.1 in Inspect mode.
3. Only the `Target`, `Page` and `Runtime` CDP domains are used. `Runtime.evaluate` runs only the snippet from `buildInjectionSource` (CSS embedded with `JSON.stringify`) or the constant `READ_APPLIED_CSS`. Both are in `src/cdp/injection.ts`.
4. Logs never contain Slack message content. CDP events are not logged.
5. The only child processes are Slack itself, `pgrep`, `lsof` and `osascript`.

Never add `--remote-allow-origins=*`: it would let any web page open in a browser drive Slack while Inspect mode is on.

Anything in `styles/` is applied to Slack as written. An `@import url(...)` would make Slack fetch that URL, so do not use one.
```
